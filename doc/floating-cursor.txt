*floating-cursor.txt*   A cursor that drifts, bobs, and surfs in Neovim

==============================================================================
INTRODUCTION                                              *floating-cursor*

floating-cursor turns the blocky terminal cursor into something with a little
mass. Short motions spring and settle. Long jumps ride a sine-wave path with
a fading water wake. When you stop, it keeps a quiet idle bob — like the
cursor is floating on the swell instead of sitting on the glass.

Requires Neovim 0.9 or newer.

==============================================================================
COMMANDS                                           *floating-cursor-commands*

:FloatingCursorToggle
    Enable or disable the animation.

:FloatingCursorEnable
    Start the floating cursor.

:FloatingCursorDisable
    Restore the ordinary cursor and close overlay windows.

:FloatingCursorOcean
    Toggle a bottom overlay of filled waves (crests and troughs)
    while you keep editing.

==============================================================================
CONFIGURATION                                        *floating-cursor-config*

>lua
    require("floating_cursor").setup({
      stiffness = 0.22,
      damping = 0.32,
      surf_distance = 8,
      wave_amplitude = 4.6,
      wave_cycles = 2.5,
      hide_real_cursor = true,
    })
<

See the README for the full option list.
